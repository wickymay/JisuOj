# 题目资料库

`/problems` 默认显示科幻资料库，也可以通过右上角切回列表。

- 资料舱使用按需加载的 Three.js / WebGL 三维场景：暖灰白、石墨色与杏金信号，档案有真实厚度、边框、光学环和题号标签；选中题目抬升，阵列产生衰减波浪。
- 中央有编号的档案对应本页真实题目，左右无编号阵列是非交互的装饰储存槽，不代表额外题目，也不会伪造数据。
- 鼠标移到资料舱后，滚轮切换题目；点击资料卡或底部索引也可选中。
- 聚焦资料舱或卡片后，方向键切换，Home / End 定位本页首尾，PageUp / PageDown 换页，Enter 打开题目。
- 页面严格限制为一个视口，没有整体滚动条。移动端在三维区横向或竖向滑动切换题目；下方详情区独立滚动，“打开题目”固定在屏幕底部。
- 本页边缘再次滚动可进入相邻页，也可以使用上一组 / 下一组。惯性尾段不会自动跨过多页。
- 右侧显示当前题目标题、来源、描述摘要、资源限制、评测方式及提交统计。“打开题目”进入原有做题页面。
- 搜索按题号或标题匹配，支持来源筛选。详情请求延后 180ms，取消已过时的请求，并缓存最近 60 份详情。
- 静态模式关闭视差、惯性与呼吸动画，渲染仅在状态变化时执行；自动尊重系统的减少动态效果偏好。页面隐藏后停止绘制，离开页面释放几何体、纹理、材质与 WebGL 上下文。
- WebGL 初始化失败或上下文丢失时，自动切换到可选题的轻量档案视图；右上角保留普通表格列表。

## 参考与素材

视觉方向参考用户提供的视频《莱茵生命主题博客演示》，以及公开的 [RhineLab Blog Theme 设计说明](https://github.com/JesseLee-CN/rhinelab-blog-theme/blob/main/DESIGN.md)。尝试下载开源仓库时 GitHub 连接失败，当前实现没有复制其源代码、GLB、字体、图片、游戏标志或音频；几何模型、标签与阴影均由本项目代码在浏览器中生成。

新增依赖 `three` 及开发类型包 `@types/three`。三维模块动态导入，核心与渲染器独立分包；保留依赖的 MIT 许可。没有后端接口或数据库变更。

## 运行与验收

使用项目既有前后端启动方式。更新后先安装依赖：

```powershell
cd frontend
npm install --ignore-scripts
npm run build
node --test scripts/archive-motion.test.mjs
```

若本地公开题目过少，可使用独立的本机 UI 测试数据服务验证多题效果。此服务只有内存中的 24 道虚拟题，不连接数据库，也不参与生产构建：

```powershell
# 终端一，在 frontend 目录
node scripts/archive-preview-fixture.mjs

# 终端二，在 frontend 目录；单独使用 5174，避免与真实数据预览混淆
$env:VITE_DEV_API_TARGET = 'http://127.0.0.1:8082'
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

访问 `http://127.0.0.1:5174/problems`。搜索 `error-fixture` 可验证接口失败提示；输入不存在的标题验证空状态。虚拟题目详情有不同延迟，可验证快速选题后没有旧详情覆盖新题目。测试滚轮、点击、Home / End、跨页、静态模式与列表模式，并在桌面及手机视口检查文档尺寸不超过视口。测试结束停止两个进程；重新启动真实数据前端时移除该终端的 `VITE_DEV_API_TARGET`，或设置为实际后端地址。
