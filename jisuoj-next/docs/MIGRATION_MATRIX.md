# 功能迁移矩阵

| 领域 | 当前状态 | 新实现 / 兼容方式 |
|---|---|---|
| 登录、注册、旧密码 | 已迁移 | Spring Security、JWT Cookie、BCrypt 渐进升级 |
| 题库与题目详情 | 已迁移 | Vue 页面 + Problem API，兼容旧表 |
| 提交与状态 | 已迁移 | 新 API 写旧提交表，UDP 通知判题器 |
| Linux 判题 | 兼容迁移 | 独立 judge-agent，复用 HUSTOJ C++ 核心 |
| 竞赛与榜单 | 已迁移 | 列表、私有加入、题目和 ACM 排名 |
| 排名与用户主页 | 已迁移 | 排名、资料、解题记录、关注、留言 |
| 公告、讨论、站内信 | 已迁移 | REST API + Vue 页面 |
| 题目管理 | 已迁移 | 新增、修改、软删除、恢复及管理表单 |
| 竞赛管理 | 已迁移 | CRUD、题目编排及管理表单 |
| 用户与角色管理 | 已迁移 | 查询、禁用、角色授权及管理页面 |
| 自研拉题 | 已重构 | 来源适配器、可选 AI、人工审核、ZIP、审计、JudgeData |
| 打印队列 | 旧站兼容 | 第二阶段补管理 UI |
| 气球派发 | 旧站兼容 | 第二阶段补比赛工作台 |
| 代码分享 | 旧站兼容 | 第二阶段补编辑器与权限 |
| 远程判题管理 | 旧站兼容 | 需先梳理节点协议，再迁移 |
| AI 题解队列 | 旧站兼容 | 与拉题 AI 解耦，后续设计独立任务队列 |
| 批量导入导出 | 旧站兼容 | 后续以受审计的后台作业迁移 |

旧站兼容项在迁移期仍由原管理页承担，完成第二阶段后再逐项关闭旧入口。
