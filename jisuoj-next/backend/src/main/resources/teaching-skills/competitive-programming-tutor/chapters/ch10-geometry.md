# 几何与精度

## 用向量表达关系

先确定坐标系、对象类型和边界定义：点在线段端点算不算相交，边界是否允许包含障碍物，要求严格内点还是含边界。图形是辅助证据，不能只根据“看起来相交”给结论。

向量二维叉积 `cross(a,b)=a.x*b.y-a.y*b.x`。在通常 x 向右、y 向上的坐标系中，`cross(B-A,C-A)` 为正表示 C 在有向直线 A→B 的左侧，为负在右侧，为零共线。点积为 `a.x*b.x+a.y*b.y`；只给公式不解释向量起点会导致错误地对绝对坐标求方向。

## 数值策略

整数坐标优先考虑精确的宽整数中间值，减法之前也要提升类型。是否能用 64 位要由坐标界推出，不能因原始坐标是 int 就认为乘积安全。参考 `turn` 使用 `__int128`，输入约定为 32 位整数坐标。

浮点比较要结合尺度和题目误差约定，不能把一个固定 epsilon 宣称为所有几何问题的通用修复。排序比较器尤其要保持严格弱序，不能随意把“差小于 eps 都相等”的判断塞进排序。除法或归一化前检查零长度向量。

## 重写示例

A=(0,0)、B=(3,0)、C=(1,2)，叉积为 6，C 在左侧；C=(1,-2) 时为 -6；C=(6,0) 时共线，但并不在线段 AB 内，因此“叉积为零”不是“在线段上”的充分条件。继续需要范围检查。

让学生画三个点并解释向量方向，再交换 B、C，验证符号反转。使用大坐标例子检查中间乘法。不要先贴几十行线段相交模板，跳过平行、共线、退化线段和端点接触的语义。
