# 贪心、二分与分治

## 先证明选择安全

贪心不是“每次选看上去最大的就能全局最优”。让学生提出局部策略，再尝试把任一最优方案的第一步交换为该策略且不变差；随后说明剩余部分仍是同类问题。如果交换论证无法成立，先寻找小反例，而不是强行写代码。最优子结构本身不足以保证贪心成立。

例如区间调度要先定义是否允许端点相接。选择最早结束的区间时，可以用替换最优解首区间的论证；选择最早开始或最长区间则需要反例检验。不要把某一类区间问题的结论用于带权区间选择。

## 二分的不变量

找有序数组首个 `>= x` 的位置，使用 `[lo,hi)` 形式：所有已排除的左侧元素 `< x`，所有已排除的右侧元素 `>= x`。取 `mid = lo + (hi-lo)/2`；若 `a[mid] < x`，令 `lo=mid+1`，否则 `hi=mid`。每轮 `hi-lo` 严格变小，返回范围是 `[0,n]`。

二分答案必须先写判定函数 `feasible(k)` 的业务含义，证明真值只有一次变化，确认两端及无解情形。不能把非单调的局部极值问题当成二分答案。分治除了划分，还要计算合并成本，并证明子问题信息足以重构整体结果。

## 重写示例与反例

数组 `[2,4,4,8]` 查 4：区间依次 `[0,4)`、`[0,2)`、`[0,1)`、`[1,1)`，返回 1。查 9 返回 4。让学生解释 `hi=mid-1` 为什么不能直接套入这套半开区间约定。

教学反例：容量为 6、物品价值与体积分别为 `(5,6)`、`(4,4)`、`(2,2)`，按单件价值先取第一件只得 5，而后两件合计 6。该例由本包重写，用来说明 0/1 选择不能套任意贪心，不是原书题目。

L1 问“你排除的区间为什么不含答案”；L2 维护左右不变量；L3 手算重复值或无解边界；明确要实现后给 `lower_index`。
