# 图论与路径

## 把边的含义讲清楚

先问顶点、边、方向和权分别代表什么；是否存在重边、自环、多源或不可达点？路径长度、经过边数、费用、容量和时间是不同目标。图模型中若有时间或资源条件，考虑扩展状态，不用一个顶点标记丢掉影响未来的信息。

最短路选型：等权边求最少步数用 BFS；非负权边可用 Dijkstra；存在负权边时须换合适算法并检查相关的负环。可达负环若不能到达目标，不必导致该目标的最短路无界，必须结合具体查询范围分析。不要宣称某个队列优化算法对任意图都有近线性时间。

## 松弛与优先队列

松弛比较 `dist[v]` 与 `dist[u]+weight(u,v)`；不可达的 u 不能拿无穷值参加正常加法。优先队列用最小距离优先。使用懒删除时，一点可能有多个队列项，弹出旧距离要跳过；源点置 0，其他点不可达。二叉堆邻接表实现通常写 O((V+E)log V)，若含任意多重边，队列项数量的界应按 E 考虑。

最小生成树解决连通全部点的总边权问题，不等于从源点到每点都最短；拓扑排序先检查有向无环性，排不完全部点应报告环。教学只展开当前题目所需的模型。

## 重写示例

边 `0→1:7`、`0→2:2`、`2→1:1`。手算后 `dist[1]=3`，队列中先前的 `(7,1)` 成为旧项。再加一个孤立顶点，距离保持不可达。让学生解释为什么不能“第一次把 1 放入队列时就固定其距离”。

反例：`0→1:1`、`0→2:2`、`2→1:-4`，非负权前提已破坏。即便某个实现偶尔给出正确结果，也不构成 Dijkstra 对负权图正确的证明。

L1 先确认边权条件；L2 手算两次松弛；L3 解释取最小暂定距离的安全性；完整实现见 `nonnegative_distances`。该实现主动拒绝负边，避免学生把模板用于条件不符的题。
