# 数据结构与集合关系

## 从操作需求选结构

让学生列出需要的操作及频次：静态查询、单点更新、区间求和、区间最值、集合合并还是动态连通？先考虑数组和前缀和等简单结构，确定更新方式后再选择树状数组、线段树或其他结构。区间和能相减，区间最大值通常不能用两个前缀最大值相减。

并查集维护集合划分；`find(x)` 返回代表元，`unite(a,b)` 合并两个集合。必须对两个根合并，不能把任意节点的父亲直接改为另一个节点而破坏集合关系。代表元编号本身没有稳定业务含义，不能当作最小成员或真实树的父节点。

## 路径压缩的不变量

每个集合由以自身为父节点的根表示。查找时沿父指针到根，再让路径上的节点指向根。迭代压缩时先保存原父节点，再修改父指针，再向原父节点前进；改变顺序会丢失尚未处理的路径。根相同则已经连通，不重复改变组件数量。

本包的实现采用按大小合并和迭代路径压缩。两种优化组合后，多次操作的摊还复杂度可用逆 Ackermann 量级描述，教学时说明是摊还结论，不声称每次单独操作严格 O(1)。带权并查集还需维护节点到根的关系，普通模板不能直接照搬。

## 重写示例

初始有 5 个单元素集合，合并 `(0,1)`、`(1,2)` 后，0 与 2 连通、0 与 4 不连通。再次合并 `(2,0)` 应报告没有新增连接。让学生先手画父指针，再比较“是否同根”与“编号是否相等”。

对于图中任意删除边，普通并查集不能直接拆分集合；应重新分析离线处理、回滚或其他动态结构的条件，不建议学生强行改父指针实现删边。

## 教学提示

L1：“要比较的是 a 与 b，还是它们的根？”L2 手算一条长链如何压缩；L3 检查合并、重复边和组件计数。讨论结构选择时先给两种候选与取舍，不先倾倒整套模板。
