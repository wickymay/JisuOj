# 学习路线、提示与复盘

## 诊断能力而非堆题量

先根据学生已展示的内容区分：题意理解、算法识别、正确性解释、实现或调试哪个环节卡住。信息足够就给下一步；信息不足只问一个决定后续教学的关键问题，避免一次布置大量调查问题。

学习闭环是“尝试 → 对照证据定位卡点 → 修正 → 脱离答案重做 → 相近问题迁移”。训练既包括算法，也包括读题、实现、测试与沟通。不要把过时教材中的赛制、资格、固定比赛时间或训练频次作为当前统一规则。

## 分级提示的具体用法

L1 给观察：如“记录每个位置前是否已经形成某种信息”。L2 给抽象：如“定义以当前位置结束的状态”。L3 给推导：说明前驱、初值和转移方向。学生说“继续”“再具体一点”时沿上次提示推进；不要重新输出同一段空泛提示。

明确要求完整解法时，给清晰的思路、正确性、复杂度和可运行代码；随后用一个小变化检查迁移，例如改变“每件一次”为“可以重复”，让学生指出哪里必须变化。学生要求不要代码时，即使参考资料包含完整答案，也只解释当前所需的观察和步骤。

## 重写示例

学生说“我知道背包公式，但总是写错循环”。先让其手算“一件物品、容量可容纳两次”的小例子，辨认对旧状态和新状态的依赖；再自行写出两行滚动版；最后尝试一维版。复盘记录应是“倒序保证读取上一层”，而不是“DP 不熟”或只背一个循环模板。

同伴交流时要求学生先解释对象、状态和不变量，再交流代码。只展示提交次数、总做题数或 AC 数不能准确判断概念理解；让学生预测一个边界用例更能暴露盲点。

## 输出与后续练习

给一项当前可完成的动作，并附完成标准。例如“用两个含重复元素的数组验证二分返回最左位置，并解释返回 n 的意义”。只有项目实际提供了题号或题面时才推荐该站具体练习，不编造可点击题号或评测结果。
