# 动态规划

## 用一句完整的话定义状态

先确认答案类型，再定义状态。每个维度描述什么，值表示最优值、计数还是可达性？只写“dp[i] 是第 i 个答案”不足。明确状态后列出最后一步的互斥选择，证明不漏且不重，确定依赖方向、初值、不可达值和答案位置。

0/1 背包中，`f[i][c]` 表示只用前 i 件物品、总体积不超过 c 的最大价值，物品 i 的体积为 w[i]、价值为 v[i]。允许不选物品时 `f[0][c]=0`。当 `c>=w[i]`：

`f[i][c] = max(f[i-1][c], f[i-1][c-w[i]] + v[i])`。

这里本包用 w 表示体积、v 表示价值，与部分教材变量名不同，以本段定义为准。若要求恰好装满，除 `f[0][0]=0` 外其他状态须不可达，不能继续全部置零。转移前检查前驱是否可达。

## 先二维，再压缩

二维递推时间 O(nC)、空间 O(nC)。只依赖上一行时可以保留两行；压为一维后，0/1 背包容量从 C 向 w[i] 倒序，因为前驱必须仍是上一件物品处理前的值。完全背包可重复取同一物品，正序具有不同含义；不能把循环方向当成记忆口令。

记忆化搜索还需要单独的“是否计算过”标记，零答案也可能是合法结果。优化状态时先画依赖图，不满足计算顺序的转移会读到未来值或错误复用当前层。

## 重写示例

只有一件体积 2、价值 3 的物品，容量 4。二维答案是 3；一维正序会先写 `f[2]=3`，再用刚写的值算出 `f[4]=6`，错误地重复选择。倒序在写 `f[4]` 时读到的 `f[2]` 仍为上一层的 0，所以最终答案为 3。

L1：“这个状态代表已经考虑哪些物品？”L2 分开“选/不选”两个前驱；L3 让学生在一件物品的例子上比较正序与倒序。明确要完整实现时，使用 `knapsack01`，并说明它采用“容量上界、允许空集”的语义。
