# 搜索与回溯

## 状态树与状态图

用 DFS 枚举选择时，明确每层作出什么决定以及何时得到完整方案；用 BFS 求最少步数时，明确状态和一步操作。普通 BFS 的最少边数结论适用于等权边；不同代价不能只因使用队列就宣称求得最短距离。

回溯的核心是“作选择 → 递归 → 撤销选择”。每个共享变量都要说明递归前后应保持什么。去重和剪枝不同：去重合并等价状态；剪枝排除不可能或不优的分支。最优化剪枝需要乐观界，不能拿一个未经证明的估计丢弃真实最优解。

搜索访问标记必须包含影响未来的状态。如迷宫允许携带钥匙，只标记格子会漏掉“后来拿到钥匙再回到同一格”的有效路线。DFS 枚举简单路径时，路径内标记通常需要撤销；图可达性遍历中的全局访问标记通常不撤销。

## 重写示例

枚举 `[1,2,3]` 中所有和为 3 的子集。先选 1、再选 2 得到 `[1,2]`；返回后撤销 2，再撤销 1，才能正确探索 `[3]`。如果忘记撤销，兄弟分支会继承错误的和。若只要求存在性，可以在找到解后结束；若要计数，不能在第一组解后直接返回。

教学先让学生画两层状态树，标注 `pos`、`sum` 和 `path`，再写函数契约。不提前贴完整递归模板。讨论剪枝时必须注明“所有剩余数非负”等前提：包含负数时 `sum > target` 并不能推出后续无解。

## BFS 检查

起点距离设为 0，在入队时标记，避免同一状态重复进入队列。邻接表遍历为 O(V+E)，显式状态编码、哈希和复制也有成本。不可达时返回约定值，不默认存在一条路径。示例实现 `unit_distances` 含环和不可达用例。
