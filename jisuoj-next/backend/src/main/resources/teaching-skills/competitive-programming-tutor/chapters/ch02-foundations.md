# 语言与实现基础

## 从表示到实现

先讲数据表示和约定，再讲语法。数组、字符串、图顶点分别采用什么下标？区间是 `[l,r)` 还是 `[l,r]`？函数返回的是元素位置、插入位置还是元素值？同一个例子中保持约定一致。`lower_bound` 返回尾后位置是合法结果，但不能解引用该位置。

递归函数需要说明参数代表的子问题、终止条件、返回值和规模下降方向。共享数组是否会被子调用修改？若修改影响兄弟分支，要还原；若函数只为寻找任一解而立即整体退出，成功分支可以不还原，但不能把这种写法用于枚举全部方案。

标准库操作也有成本：排序、复制容器、按值传参、字符串拼接和集合查询都要纳入复杂度。不要把 `vector` 插入到任意位置当成常数时间，也不要在迭代器可能失效后继续使用它。

## 数值与输入检查

- 先估算中间值，再决定类型。把乘积赋给 `long long` 并不能修复之前在 `int` 上发生的溢出，应在乘法前提升类型。
- 有符号溢出不能当成稳定取模行为。涉及乘积、面积、最短路和累计和时分别检查范围。
- 输入解析遵从当前题面：多组直到 EOF、测试组数或哨兵结束不能混用。调试输出不应混入标准答案。
- 多组数据中检查容器、计数、距离、访问标记和缓存是否重新初始化。

## 重写示例

讲解“在有序数组中找首个不小于 4 的位置”时，用 `[1,4,4,7]` 得到下标 1，再换成空数组得到 0，换成 `[1,2]` 得到 2。让学生指出最后一个返回值能否直接用 `a[pos]`。答案是必须先检查 `pos < a.size()`。

示例代码见 `examples/verified_algorithms.hpp` 的 `lower_index`。这是一份独立重写的 C++17 教学实现；它的测试覆盖空数组、重复值、首尾和不存在的目标，不声称它是原书代码原样通过评测。

## 分级教学

L1 先问“这个变量表示值还是位置”；L2 明确区间和返回约定；L3 手算一次迭代并检查终止；需要完整代码时才展开实现。学生只问一处语法时，用最小片段解释，不重新讲整本 C++。
