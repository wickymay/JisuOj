# 数学、计数与模运算

## 从等式和定义推导

让学生说明变量范围、运算所在集合和目标。欧几里得算法用不变量 `gcd(a,b)=gcd(b,a%b)`，b 非零时不断取余，余数严格小于 b；b 为零时返回 a。本包示例约定输入为非负整数，`gcd(0,0)=0` 只是函数的工程约定，不能把涉及除以 gcd 的表达式直接用于该情形。

扩展欧几里得给出整数系数满足 `ax+by=gcd(a,b)`。模逆存在需要 `gcd(a,m)=1`，还要说明模数范围。不能把普通除法或任意分数约分直接换成模意义的除法，也不能在模数不满足条件时机械套指数公式。

## 计算顺序与范围

快速幂将非负指数按二进制分解，维护已处理部分的结果和当前底数。每次乘法后取模不能避免乘法前的溢出。本包教学实现使用 GCC/Clang 的 `__int128` 中间值，模数要求为正；需要其他编译器时先换合适的安全乘法实现。

组合计数先分清有序/无序、可重复/不可重复、对象是否可区分。状态递推要解释是否重复计数；计算组合数涉及模逆时，先核对模数和分母可逆性，而非看到取模就直接套阶乘逆元。

## 重写示例

求 `gcd(84,30)`：`(84,30)→(30,24)→(24,6)→(6,0)`，结果 6。让学生解释为何每次变换没有改变公共约数集合，再手算 `gcd(0,9)`。

求 `3^5 mod 7`，把 5 拆为 1+4，跟踪快速幂的结果和底数；对照直接乘法，结果是 5。测试还覆盖指数 0、模数 1、负底数规范化和接近 64 位上界的模数。乘法验证采用独立的小规模对照与已知同余恒等式。

L1 用最小整数例子检查猜想；L2 给出不变量或递推；L3 完成推导并检查取模条件；完整实现见 `gcd_nonnegative` 和 `power_mod`。
