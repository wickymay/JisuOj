# 字符串与匹配状态

## 先固定下标定义

字符串匹配教学先用朴素算法说明重复比较。KMP 保存已匹配前缀长度，使文本指针无需回退。本包使用零基 `pi[i]`：模式串 `p[0..i]` 的最长真前缀且为后缀的长度；它不是字符下标，也不包含整段自身。教材中的 `Next` 可能采用另一套下标，必须按定义转换，不能混搭公式。

计算 pi：从 `j=pi[i-1]` 开始，失配时不断令 `j=pi[j-1]`，匹配则递增 j。寻找模式时也用同一回退链；每次报告完整匹配后回退到 `pi[m-1]`，才能保留重叠匹配。解释 O(n+m) 时用指针增长与回退的摊还界，不声称每个字符绝对只参加一次比较。

## 重写示例

模式 `abab` 的 pi 是 `[0,0,1,2]`。在文本 `ababab` 中，起点为 0 和 2 的两次匹配重叠。第一次完成后 j 应回到 2，而不是清零。用 `aaaa` 匹配 `aa`，应得到 0、1、2；该例能揭示丢失重叠匹配的错误。

空模式的语义须单独约定：本包参考函数返回所有 n+1 个插入位置；实际题目若保证模式非空，说明该前提即可。字符串按字节还是 Unicode 字符处理应与题目字符集一致，不把 C++ `string` 的一个字节自动当成一个汉字。

## 选型与边界

单模式线性匹配可用 KMP；多模式可考虑 Trie/AC 自动机，但建树、字符集、转移结构和输出匹配数会影响复杂度，不能笼统说“任何多模匹配都是 O(n)”。哈希匹配应说明碰撞条件；正确性要求严格时考虑验证或确定性算法。

L1 问“失配前哪一段已经知道相等”；L2 画前缀和后缀重叠；L3 在重复字符上追踪回退；明确需要实现后参考 `prefix_lengths` 与 `match_positions`。不要通过截取模式串和文本的长副本破坏原本线性成本。
