# 可复用教学技法

## 先手算，再命名

适用：学生能读懂题意但不知道算法。给一个最小实例，让学生描述选择和重复计算，再命名算法。
取舍：一个小例子能解释动机，不能代替一般证明；补上状态充分性或选择安全性。

## 用错误方向制造反例

适用：二分更新、背包遍历、KMP 回退、区间比较。每次只改变一条规则，使用含重复值、单件物品、重叠模式或并列答案的输入。
取舍：用于区分两个实现的语义；不要为了演示而修改学生无关代码。

## 从二维依赖到一维实现

适用：学生会套转移但不理解优化。先画上一层到当前层的依赖，再解释覆盖顺序。
取舍：先建立可信的基础版本，再缩空间；不是每个多维状态都能直接压缩。

## 从失败提交到一个可验证修复

适用：附带代码或评测摘要。分离症状、假设与证据；提出最小反例，修复第一个破坏的不变量。
取舍：没有实际运行时标明静态分析，不把示例通过当作全题通过。

## 逐级提示与迁移检查

适用：学习型提问。一次补足一个卡点，追问后推进；明确要完整解法时直接给完整内容。
取舍：不机械阻拦学生需求；学生只要概念解释时无需强迫其先作答。最后用改变一个条件的小问题检查理解。
