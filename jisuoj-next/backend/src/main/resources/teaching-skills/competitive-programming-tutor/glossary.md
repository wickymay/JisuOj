# 教学术语

**BFS（广度优先搜索）**：逐层探索状态；等权边条件下得到最少边数，见 ch03。

**DP（动态规划）**：按依赖关系复用子问题结果的算法设计方法，见 ch05。

**KMP**：借助模式串前后缀信息避免文本指针回退的匹配算法，见 ch08。

**二分不变量**：迭代前后保持、足以说明答案仍在候选范围的条件，见 ch04。

**交换论证**：把一个最优解的局部选择换成所提策略且不变差，用于证明选择安全，见 ch04。

**充分状态**：保留所有会影响未来合法选择和收益的信息的状态，见 ch01。

**回溯还原**：一个分支结束后恢复共享变量，使兄弟分支从正确状态开始，见 ch03。

**复杂度**：随输入规模增长的计算或存储成本，包含状态数、转移和预处理，见 ch01。

**松弛**：用一条经由已知路径的候选距离更新目标距离，见 ch06。

**路径压缩**：把查找路径上的节点直接连接到集合根，见 ch07。

**最优子结构**：最优解可由相关子问题的最优解构成；本身不保证任意贪心正确，见 ch04、ch05。

**不可达状态**：不对应任何合法方案的状态，必须与数值为零的合法状态区分，见 ch05、ch06。

**摊还分析**：对一串操作的总成本给出界，而不是宣称每个操作都满足同一最坏常数界，见 ch07、ch08。

**最小反例**：经过缩减仍能触发目标错误的简单输入，见 ch11。

**分级提示**：本项目从观察、抽象、推导到完整实现的教学设计，见 ch12；不是九本书共有的原始术语。
