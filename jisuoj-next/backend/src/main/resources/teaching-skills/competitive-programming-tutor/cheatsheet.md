# 算法与教学决策速查

| 观察 | 下一步 | 必须检查 |
|---|---|---|
| 不清楚输入和目标 | 先抽取对象、操作和约束 | 不补造缺失条件 |
| 存在简单暴力 | 估算规模并留作小输入对照 | 初始化、多组、复制成本 |
| 要求最少步数 | 判断是否等权状态图 | 权值不同不直接套普通 BFS |
| 权值非负的最短路 | 考虑 Dijkstra | 负边、不可达、距离溢出 |
| 一个判定随参数单调变化 | 考虑二分答案 | 真值方向、端点、无解 |
| 每步局部选择看似最优 | 尝试交换论证或构造反例 | 最优子结构并不充分 |
| 子问题重复且状态可充分描述 | 考虑 DP/记忆化 | 状态含义、初值、依赖方向 |
| 0/1 背包一维优化 | 容量倒序 | 前驱来自上一层 |
| 只需维护集合合并与连通 | 考虑并查集 | 根合并、不能直接删边 |
| 单模式匹配重复回退文本指针 | 考虑 KMP | pi/Next 定义、重叠匹配 |
| 模意义下除法 | 先判断可逆 | gcd、模数与零值 |
| 几何方向和边界 | 向量叉积并分类退化情形 | 数值范围、共线不等于在线段 |
| 只要提示 | 给当前一级的观察与检查点 | 不泄露完整实现 |
| 明确要完整解法 | 思路、证明、复杂度、实现、边界 | 不冒称代码已评测通过 |
| WA 但主值似乎正确 | 查并列规则和开闭边界 | 最短、最早、字典序 |

没有统一适用于所有机器的“某数量级必过”规则。结合实际时间限制、语言、常数及输入形态作有条件判断。
