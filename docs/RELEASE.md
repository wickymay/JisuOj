### 更新内容

### 提交方式

在仓库根目录核对改动后，可使用以下 PowerShell 命令自行提交。`safe.directory` 只对单次命令生效，用于兼容本发布副本最初由不同本地账户创建的情况，不修改全局 Git 配置。

```powershell
$releaseRepo = (Get-Location).Path.Replace('\', '/')
git -c "safe.directory=$releaseRepo" status --short
git -c "safe.directory=$releaseRepo" add .
git -c "safe.directory=$releaseRepo" diff --cached --stat
git -c "safe.directory=$releaseRepo" commit -m "feat: add AI test data generation and import drafts"
git -c "safe.directory=$releaseRepo" push origin main
```
