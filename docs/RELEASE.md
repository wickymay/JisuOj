# v0.1.0 源码基线

整理日期：2026-10-20。此版本记录当前 JISUOJ 的可构建源码和迁移状态，用于继续开发与部署验证。

## 发布内容

- 新版 Vue 3 / TypeScript 前端、Spring Boot / Java 17 后端。
- HUSTOJ Linux 判题源码、初始化数据库结构和 PHP 兼容站点。
- 12 个专题的 AI 教学方法、重写的算法示例及可选检索服务源码。
- 环境变量模板、Compose 配置、启动与首个管理员说明。
- GitHub Actions 前端、后端、教学资源及检索服务检查。

本地开发项目位于另一目录；本发布副本独立整理，未修改运行中的原站。发布副本中的本机密钥被移除，数据库密码使用占位值，Compose 要求显式提供数据库和认证密钥。RAG 默认关闭，需要另外准备有使用权限的模型与知识库。

依赖源码中保留原版权和第三方许可证。上游基础提交为 `91b50c86aac788ce1ff70beac462ae5f35180e5a`，定制代码来源于现有本地工作副本。
